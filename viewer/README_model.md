# viewer_model.html — V3 Mathematical-Model Viewer

Interactive map of the unified operator `L = M⁻¹K` and its four domains
(mass / Coulomb / temperature / velocity). Click a domain node for its verified
numbers, document, and script. Tabs: domain detail · machine-precision rule ·
enrichment→machine-precision (P1→P8) · honest scope (earned / not-earned / vs SOTA).

ALL displayed numbers come from `data_model.js`, which holds verified output from the
scripts in `src/verification3d/` — no physics runs in the browser (presets only),
matching the project architecture. See `theory/07_v3_synthesis.md` and `06z` audit.
